# Duck Sword Minecraft Plugin

A Minecraft plugin that adds a golden sword shaped like a duck, which releases four baby chickens (ducklings) whenever you attack an entity. The ducklings will automatically target nearby monsters and fight on your behalf. This fun and whimsical plugin is designed for Paper 1.21 servers and brings a quacking twist to combat.

## Install

1. Download the latest `plugin.jar` file from the releases section.
2. Stop your Minecraft server.
3. Place the `plugin.jar` file into your server's `plugins` folder.
4. Start your server.

## Use

1. Once the plugin is enabled, use the command `/duck` to receive a Duck Sword in your inventory.
2. Equip the Duck Sword in your main hand.
3. Attack any mob or entity on your server.
4. Four baby chickens will spawn near the target, with speed buffs, and will immediately attack nearby monsters.
5. Enjoy watching your duckling army fight for you!

### Requirements
- Paper 1.21 or newer
- Java 21 or newer
